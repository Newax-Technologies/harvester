# Harvester Keyword Depth v2.0 Summary

Status: **Proposed**  
Date: **5 August 2026**

This short summary exists for reviewers who need the v2.0 change boundary without reading every registry before breakfast.

The change adds:

- a 32-dimension ultimate keyword-profile standard;
- controlled keyword expansion and query composition;
- provider-offering-specific intent, pain, replacement, integration, technology, event, contradiction, and buying-stage profiles;
- semantic, entity, facility, relationship, and classification-code expansion controls;
- source-specific query and evidence templates;
- a Pakistan English, Urdu, Roman Urdu, and mixed-language candidate pack;
- profile-level benchmark, gold-set, regression, shadow-rollout, and activation requirements;
- an explicit matrix separating defined documentation from pending authoritative data, review, runtime engineering, testing, activation, and completion.

The change does not implement search execution, source adapters, schemas, APIs, embeddings, classifiers, scoring, outreach, or production activation.

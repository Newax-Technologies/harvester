# Keyword Plan Preservation Rule

Status: **Proposed**  
Version: **1.0**  
Date: **5 August 2026**

The Harvester keyword development plan must be maintained additively.

It must not replace, collapse, regenerate, or silently rewrite existing domain, activity, control, signal, source, role, contact, query, evidence, or cross-product keyword registries.

Any future change to an existing registry requires:

1. A specific reason.
2. The affected stable codes.
3. Positive and negative benchmark evidence.
4. Compatibility review.
5. A new registry or profile version.
6. Review and approval.
7. Rollback capability.
8. Exact-commit verification.

The current plan files are:

- [Keyword Profile Development Plan](keyword-profile-development-plan.md)
- [Keyword Plan Application Map](keyword-plan-application-map.md)
- [Keyword Plan Status](keyword-plan-status.md)

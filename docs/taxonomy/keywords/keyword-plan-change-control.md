# Keyword Plan Change Control

Status: **Proposed**  
Version: **1.0**  
Date: **5 August 2026**

Changes to the keyword development plan or any linked registry must remain reviewable and traceable.

Required change record:

| Field | Requirement |
| --- | --- |
| Change reason | Explain the business, relevance, evidence, or quality problem being corrected |
| Affected layer | Domain, activity, organization cue, exclusion, offering signal, sector overlay, source, role, contact, locale, query, or evidence rule |
| Stable codes | Identify every affected canonical code |
| Compatibility | State whether historical target profiles and harvest jobs remain interpretable |
| Benchmarks | Include known-positive, known-negative, ambiguous, stale, duplicate, and contradictory cases as applicable |
| Version | Create a new version rather than silently mutating the prior approved profile |
| Approval | Record reviewer and approval status |
| Rollback | Preserve the previous approved version |
| Verification | Record the exact commit and applicable checks |

The governing preservation rule is defined in [Keyword Plan Preservation Rule](keyword-plan-preservation-rule.md).
